# FECODATLE · Federación Colombiana de Atletismo

Sitio web y panel de gestión para que la Federación Colombiana de Atletismo publique sus propios contenidos.

**Caso de estudio** · Proyecto para cliente · En producción · Código privado

## El problema

La federación se había quedado sin sitio web y no tenía dónde publicar sus noticias, documentos, calendario ni galería.

## La solución

Una web pública y un panel propio desde el que el equipo de la federación publica noticias, documentos, calendario y galería. El acceso está organizado por roles y la información tiene respaldos continuos.

## Mi papel

Participé en todas las capas del proyecto, de la idea a producción:

- **Desarrollo:** frontend, backend y base de datos, además de integraciones con MCP.
- **Puesta en producción:** configuración de dominios y publicación de versiones.
- **Calidad y mantenimiento:** revisión y corrección de errores y parches.
- **Seguimiento:** atento al estado del proyecto de principio a fin, proponiendo e implementando mejoras.

## Resultados

- **12 días** de cero a producción.
- La federación **publica sola** sus contenidos desde su propio panel.
- **100/100 en accesibilidad** en Lighthouse.
- **Más de 1.800 pruebas automatizadas.**

## Stack

Next.js · TypeScript · PostgreSQL

El código es privado: pertenece a la federación y no se publica por confidencialidad. Este repositorio solo documenta el proyecto.
